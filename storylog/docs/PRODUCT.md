# StoryLog

StoryLog is a personal media tracking application for:

- Movies
- Series
- Books
- Games

## Product direction

The long-term goal is to provide a unified place where users can discover, track, rate, and organize media across different formats.

## Current MVP

The current MVP is intentionally small.

Users can:

- View their media library.
- Add a media item.
- Specify its type.
- Add optional metadata.
- Rate it from 0 to 5.
- See the newly created item immediately in the library.

The current implementation uses in-memory state and does not persist data.

## Out of scope for the current prototype

- Search
- Filtering
- Delete
- Authentication
- Social features
- Notifications
- External metadata providers
- Image providers
- Database persistence
- Analytics
- Advanced routing
